# Working in this repository

A small static recipe page, used for live demos.

- The page is `site/index.html`, `site/style.css` and `site/app.js`. Edit only those files.
- Keep each change as small as the request needs. No new files, dependencies, frameworks or build steps.
- The page is already being served by `./serve` with live reload, so a saved edit shows up on its own. Do not start, stop or restart the server, and do not run installs, tests or builds.
- When you are done, say in one or two lines what you changed.
